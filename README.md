# Northstar Services — Local Business Service Portal

Northstar Services is a responsive demonstration portal for a simulated local service company. The project is being developed in milestones, from requirements and interface structure through customer request workflows, team management, testing and documentation.

## Project status
**Current milestone:** Day 1 — Project Foundation

The current version establishes the initial customer and team pages, shared design tokens, responsive base styling and project documentation. Enquiry submission, request tracking and team management are planned for later milestones and are not implemented yet.

## Technology
- HTML5
- CSS3
- JavaScript (vanilla)
- Google Fonts (DM Sans and Playfair Display)

## Run locally
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with a local development server, such as the Live Server extension.
4. Use the **Team Portal** link in the navigation or footer to open `admin.html`.

## Planned milestones
1. Project foundation.
2. Core customer portal and service discovery.
3. Enquiry submission, validation and request tracking.
4. Team dashboard and request status management.
5. Visual refinement and responsive improvements.
6. Testing, evidence and final documentation.

## Project limitations
This is a demonstration project. The foundation milestone does not include a production backend, database, real authentication or server-side authorization. These limitations will be reviewed as the project develops.
