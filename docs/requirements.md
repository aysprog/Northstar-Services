# Project Requirements — Northstar Services

## 1. Project overview
Northstar Services is a responsive demonstration portal for a simulated local service company. It is intended to help customers discover available services, submit enquiries and follow request progress, while giving team members a separate area to review and manage requests.

## 2. Primary stakeholders
- **Customers:** explore services, submit enquiries and track their requests.
- **Service team:** review incoming requests and update their progress.
- **Project reviewer:** evaluate usability, implementation quality, testing and documentation.

## 3. Initial scope
The project will be developed in milestones. The planned scope includes:
- Responsive customer-facing portal.
- Service information and enquiry form.
- Client-side form validation and request reference generation.
- Request tracking.
- Separate team portal with request-management features.
- Testing evidence, project documentation and deployment review.

## 4. Quality goals
- Clear navigation and readable content.
- Responsive layout for mobile, tablet and desktop.
- Accessible labels and understandable form feedback.
- Consistent visual design and reusable styling.
- Documented limitations and test results.

## 5. Current milestone
**Day 1 — Foundation:** establish the page structure, shared styling, JavaScript entry point and project documentation. Interactive workflows are intentionally scheduled for later milestones.

## 6. Out of scope for the foundation
- Real customer data or production transactions.
- Production authentication and server-side authorization.
- Live database or external service integrations.
